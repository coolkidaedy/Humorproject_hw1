# Humor Project

Next.js app with TypeScript, the App Router, Tailwind CSS, and ESLint.

## Getting started

Use Node.js 24 LTS (`nvm use` if you have nvm installed).

```sh
npm install
npm run dev
```

Open http://localhost:3000. Edit `src/app/page.tsx` to customize the homepage.
Shared layout and styles live in `src/app/layout.tsx` and `src/app/globals.css`.

## Checks and production

```sh
npm run lint
npm run build
npm start
```

`npm start` serves the production build after `npm run build` succeeds.
